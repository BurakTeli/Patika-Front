### 🚀 Features

- 🎲 Interactive Dice Roll (player vs computer)
- 🧍 Player Name Locking
- 🧠 Result Message: Win, Lose, or Draw
- 📜 Full Game History Log
- 🔁 Reset Button
- 🌙 Dark/Light Mode Toggle
- 🌐 Language Support (i18next with LanguageToggle)
