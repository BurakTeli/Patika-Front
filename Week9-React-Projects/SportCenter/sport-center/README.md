# 🏋️ Sport Center – React Project

This project is a complete, responsive web application for a fictional fitness brand called **Sport Center**, rebuilt entirely with **React** and **TypeScript** as part of a frontend bootcamp challenge.

The goal was to modularize each section of the existing HTML/CSS/JS project into professional, scalable, and maintainable React components. Each section is structured as a standalone module, consisting of reusable subcomponents and dedicated style files.

---

## 🚀 Technologies Used

- **React** with **TypeScript**
- **CSS3** (Modular structure, mobile-first responsive design)
- **React Functional Components & Hooks**
- **Modular Folder Architecture**
- **Vite / Create React App** (based setup)

---

## 🧱 Project Structure

Each major section (Navbar, Hero, Stats, Classes, BMI Calculator, Trainers, Products, Reviews, Contact, Footer) is separated into its own directory inside `/components`, with at least 3 inner subcomponents per section.  
Styling is separated in the `/styles` directory for clarity and maintainability.

---

## ✨ Features

- Fully responsive and mobile-friendly layout
- BMI Calculator with dynamic input logic
- Product list and dynamic card rendering
- Trainer showcase with hover effects
- Client review cards with structured data
- Contact form and embedded Google Map
- Modular and reusable React components
- Modern visual design with clear typography and spacing
