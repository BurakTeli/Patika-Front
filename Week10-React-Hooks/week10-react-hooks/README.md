# 📝 React Note App

This is a modern, modular Note Application built with **React** and **TypeScript**.  
The app allows users to add, update, and filter notes with color tagging and a clean UI.

---

## 🚀 Live Features

- ✅ Add notes with a title and description
- ✅ Color selection for each note
- ✅ Real-time filtering by title
- ✅ Update/edit existing notes
- ✅ Required title validation (with alert)
- ✅ Responsive layout: 4 notes per row
- ✅ Clean UI with modern CSS Grid & Flexbox

---

## ⚙️ Tech Stack

- React + TypeScript (Vite)
- Functional Components
- React Hooks (`useState`)
- Modular Component Structure
- CSS Modules (Scoped styling)
