# Spend Bill Gates' Money – React TypeScript Edition

This project is a React+TypeScript clone of the popular "Spend Bill Gates’ Money" app,  
rebuilt for learning purposes in a modular, professional, and visually engaging style.

---

## Features

- **Initial Balance:** You start with $100,000,000,000. Can you spend it all?
- **Product Catalog:** Dozens of (fictional or real) products with images, names, and prices.
- **Purchase & Sell:** Buy as many as you want (unless it’s a one-of-a-kind item!), and sell back whenever you like.
- **Dynamic Basket:** Your purchased items and their total cost are always visible at the bottom.
- **Responsive Design:** Works and looks great on any device.
- **Modern UI:** Each product, cart, and modal is designed with professional CSS and fun details.

---

## Technical Details

- **React** + **TypeScript**
- **useReducer** for global state (balance and basket)
- **Component-based architecture:** Each UI section is a separate, reusable component.
- **Responsive and clean CSS** (including modular styles for each feature)
- **Special features:**  
  - **Icardi Card:** Buy/Sell replaced by a custom button. Clicking it opens a big modal with a Galatasaray-themed background and a surprise video.
  - **Stock Limits:** Unique items (like Mona Lisa, Osimhen) can only be purchased once.
  - **Audio/Video integration** for special product actions.
