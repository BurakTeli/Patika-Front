# To-Do List App

A modern, responsive and user-friendly To-Do List web application.  
Built with **HTML**, **CSS (Bootstrap 5)**, and **JavaScript**.  
You can add, edit, complete, filter and delete your tasks — and your list is always saved thanks to LocalStorage!

---

## About the Project

This project is a simple but powerful To-Do List app designed to help you organize your daily tasks efficiently.  
It features a clean, modern interface with keyboard shortcuts and visual feedback for better productivity.

**Key Features:**

- Add, edit, delete tasks
- Mark tasks as completed or active
- Filter by All / Active / Completed
- Clear completed tasks in one click
- See live task counts for each category
- Data is automatically saved in your browser (LocalStorage)
- Export and import tasks as JSON files
- Mobile-friendly and responsive design
- Visual feedback for errors and success
- Keyboard shortcuts for quick actions

**Technologies Used:**

- HTML5 & CSS3 (with Bootstrap 5)
- JavaScript (ES6+)
- Font Awesome icons
- LocalStorage API
