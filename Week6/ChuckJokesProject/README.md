# Chuck Norris Jokes App

A simple and interactive web application that displays random Chuck Norris jokes. Built with HTML, CSS, and JavaScript using the Chuck Norris Joke API.

---

## Features

- Fetches a random joke on every page load
- "Get Another Joke" button to retrieve a new joke
- Responsive layout with clean styling
- Clear separation of HTML, CSS, and JavaScript files
- All code sections are commented and easy to understand

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, transitions)
- JavaScript (Fetch API, DOM manipulation)

## Deployment Instructions

1. Clone the repository
2. Open `index.html` in your browser
3. Enjoy the jokes!
