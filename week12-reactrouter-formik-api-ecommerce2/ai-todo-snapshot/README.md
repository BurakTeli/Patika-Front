# 📝 Todo App (AI-assisted Demo Project)

This is a simple and stylish **Todo Application** developed as a **demo project** with the help of artificial intelligence (AI). It allows users to add, complete, update, and delete todos, and provides filtering options for active and completed items.

> ⚠️ **Note:** This project was created entirely for **educational and experimental purposes**, with the assistance of **ChatGPT (OpenAI)**.

---

## 📌 Features

- ✅ Add new todo items
- ✅ Mark todos as completed
- ✅ Edit existing todos
- ✅ Delete individual todos
- ✅ Filter: All / Active / Completed
- ✅ Clear all completed todos
- ✅ Todos are saved in `localStorage`

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| **React** | UI development |
| **TypeScript** | Type safety |

| **localStorage** | Saving data locally |
