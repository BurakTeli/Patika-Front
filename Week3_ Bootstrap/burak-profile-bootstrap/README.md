# 💻 Burak - Bootstrap Developer Profile

A responsive, modern personal profile page built entirely with **HTML5**, **Bootstrap 4.5**, and custom **CSS**, without using any images.  
The project focuses on clean design, accessibility, and modular structure.

## 🚀 Live Preview

_Not deployed yet._ You can open `index.html` directly in your browser.

## 📂 Project Structure

burak-profile-bootstrap/
├── css/
│ └── style.css # Custom styles
├── index.html # Main HTML page
└── README.md # Project documentation

## 🛠️ Built With

- ✅ HTML5
- ✅ Bootstrap 4.5 (via CDN)
- ✅ Custom CSS
- ❌ No images used (icon-free & clean)
- ❌ No JS logic (optional Bootstrap JS only)

## 📌 Sections Included

- `About Me`: Brief bio and background
- `Skills`: Tech stack highlights
- `Projects`: Placeholder for portfolio
- `Contact`: Email and communication link
