# Simple Guide Website

This is a simple multi-page personal blog website built with pure HTML5 and CSS3.

## Pages Included
- `index.html` (Home Page)
- `hakkinda.html` (About)
- `servisler.html` (Services)
- `iletisim.html` (Contact)

## Features
- Responsive and clean layout
- Basic navigation between pages
- Styled with external CSS

## Purpose
Created as part of a front-end assignment to practice HTML structure, semantic tags, and CSS styling.
