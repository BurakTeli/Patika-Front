# 🧠 SpeedQuiz – Graduation Project

SpeedQuiz is a humorous and time-challenging quiz application developed as the final project of a frontend bootcamp. Users must answer 10 quirky multiple-choice questions under time pressure.

This project is built with **React**, **TypeScript**, and **Vite**, and includes animations, theme toggling, and a personalized result analysis.

---

## 🚀 Technologies Used

- React (with Vite)
- TypeScript
- Formik (for form validation)
- CSS (separate per component/page)
- Framer Motion (animations)
- React Context (state management)
- Responsive Design (Desktop & Mobile)
- Git & GitHub (for version control)

---

## 📌 Project Goals

- Build a fully functional and stylish quiz app from scratch
- Practice time-limited question display (30s per question)
- Hide answer options for the first 4 seconds
- Prevent going back to previous questions
- Display total correct, incorrect, and unanswered answers
- Provide funny, personalized feedback at the end
- Score users out of 100
